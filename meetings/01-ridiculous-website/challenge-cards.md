# Challenge Cards

Choose one prompt:

- A luxury store for ordinary rocks.
- An emergency subscription for invisible umbrellas.
- A museum of terrible excuses.
- A fan page for the school’s most boring object.
- A restaurant serving only one impossible ingredient.
- A premium service that solves a problem nobody has.

## Chaos cards

- Add a suspicious five-star review.
- Add a warning that makes the product less appealing.
- Add a “limited time” offer that has lasted 400 years.
- Add a hover effect that changes the product’s personality.
- Add a button that reveals a secret fact.
