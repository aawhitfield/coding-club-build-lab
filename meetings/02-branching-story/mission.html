Essential question

How can links turn a few files into a story another person can navigate?

  1. Play the finished storyMake a prediction before you inspect the files.

    Use the preview. Follow both choices, notice where each one lands, and tell your navigator which ending you would choose.

    DoPlay both visible links and use Restart once.
    You should seeTwo different pages and a way back to the opening.

    Turn and talk

    Which choice feels more tempting, and what consequence do you predict? There is no single correct creative answer; support your prediction with one detail from the page.

  2. Find the story mapLearn the clue before answering the question.

    Each page is a file. The visible words are the link text; the href value is the destination.

    index.htmlopening 
    <a href="choice-a.html">Open</a>

    The visitor sees “Open.” The browser opens choice-a.html.

    choice-a.htmlbranch A 
    <h1>Consequence A</h1>

    One possible consequence.

    choice-b.htmlbranch B 
    <h1>Consequence B</h1>

    A different possible consequence.

    Which file opens when a visitor clicks this link?

    <a href="choice-b.html">Ask the door</a>

    meetings/02-branching-story/project/index.html
    meetings/02-branching-story/project/index.html

    In the Codespace tab, press Ctrl+P and open the path shown above. On a Mac, use Cmd+P.

  3. Build the guided branchChange one link, then make the story yours.

    Complete the small baseline before adding complexity. Save after each change and watch the preview.

    EDIT 1 · Premise

    In index.html, change the opening heading and paragraph.

    <h1>The Door That Wasn’t There</h1> → <h1>The Vending Machine That Knew Too Much</h1>

    EDIT 2 · Choice destination

    Change one visible choice and its matching href. The words and destination should agree.

    <a href="choice-a.html">Open the door</a>

    EDIT 3 · Consequence

    Open the destination file and replace its heading and paragraph. Keep a Restart link.

    <a href="index.html">Restart</a>
    Look hereClick both choices after every edit.
    You should seeBoth branches still open and each ending feels different.
  4. Choose a disaster and test itCreativity comes after the path works.

    Complete the guided baseline first

    Choose a premise and a constraint. The constraint makes the story more surprising without making the build larger.

    Unexpected guest

    A normal school object starts giving advice.

    Two bad choices

    Both choices work, but each creates a different problem.

    Hidden third page

    Builder level: add a bonus page and link to it from one ending.

    Player test

    1. Give the preview to another team without explaining it.
    2. Ask them to reach both endings and restart.
    3. Repair one broken, unclear, or misleading link they report.
  5. Explain the pathMake your design understandable to someone else.

    Complete the team log and demo sentence. Commit with Meeting 2: branching story, sync, verify the commit, and stop the Codespace.

    Demo sentence: “Our story invites the player to ____. The choice that creates the biggest consequence is ____ because ____.”

    Stuck ladder

    1. Read the current edit and compare the link with the preview.
    2. Ask the navigator or tester to trace the href.
    3. Restore only the affected file from the starter if needed.
    4. Ask a peer, teacher, or optional AI adviser for one next step.
