  4. Choose your machineBuild for an audience, then make it delightful.

    Complete the guided baseline first

    Choose a machine for a teammate, a player, or a visitor at the showcase. Start with one of these themes if you need a spark, then make the title, lists, image, alt text, colors, and background image match that world. You may invent a better theme too:

    Suspicious Excuse Machine

    Combine a reason with an impossible detail.

    Cafeteria Fortune Teller

    Predict a lunch event and its consequence.

    Emergency Side Quest

    Generate a mission and a strange constraint.

    Random School Superpower

    Pair a power with an inconvenient weakness.

    Questionable Club Mascot

    Mix an animal, object, and dramatic title.

    Villain Name Laboratory

    Combine a title with a suspicious hobby.

    After-School Decision Machine

    Choose a plan and an unexpected complication.

    Terrible Advice Department

    Generate advice that is funny but safe.

    Give the theme a matching backdrop

    The ready-made visual swatches live in meetings/03-events-and-endings/theme-backdrops/. In style.css, change only the filename inside background-image so the page background belongs to the same world as your machine.

    background-image: url("../theme-backdrops/side-quest.svg");

    Good match: the title, result words, machine image, alt text, colors, and backdrop all tell the same story. Keep the backdrop decorative; put important meaning in the real image’s alt text and in the page text.

    Try one of these filenames: suspicious-excuse.svg, cafeteria-fortune.svg, side-quest.svg, school-superpower.svg, club-mascot.svg, villain-lab.svg, after-school.svg, or terrible-advice.svg.

    Remix

    Complete the baseline and make the theme unmistakably yours.

    Builder

    Add a second category button, a third list, or a result mood class.

    Boss

    Prevent an immediate repeat or coordinate a result object with its visual mood.

    Optional AI help starts here. Ask for ideas or one diagnosis, not a complete project.

  5. Test and repairLet another person’s evidence choose the next edit.

    Complete the guided baseline first

    Ten-click test

    1. Ask another team to press the button ten times without coaching.
    2. Record one result that was clear, one that was surprising, and one that needs work.
    3. Make one revision based on what the tester saw.
    4. Run the test again and explain what changed.

    Evidence question

    What did the tester do or say that caused your revision? Point to the result or behavior that changed.

  6. Broadcast what you builtExplain the code pattern, not just the finished screen.

    Complete TEAM-LOG.md, DEMO.md, and AI-LOG.md only if your team used AI. Commit with Meeting 3: chaos button, sync, verify the commit, and stop the Codespace.

    Demo sentence: “When the visitor clicks ____, onClick runs, pickRandom chooses from ____, and setText displays ____.”

    Stuck ladder

    1. Reread the current edit and compare it with the preview.
    2. Ask the navigator or tester to point to the exact file and ID.
    3. Compare brackets, commas, quotes, and ID spelling.
    4. Restore only the affected file from the starter.
    5. Ask a peer, teacher, or optional AI adviser for one diagnosis.
