Essential question

How can we connect a user’s input to a result, then use tests to improve it?

  1. Play the sample featureSee the full loop before you read it.

    Use the preview. Provide an input or make a choice, press the action button, and describe what appears.

    InputSomething the user types, selects, checks, or clicks.
    OutputA message, count, screen, or recommendation the user can see.

    Turn and talk

    What did the user provide? What did the program do with it? What changed on screen?

  2. Map the featureUse the paired recipe, not a mystery snippet.

    Pick one recipe. Every recipe has an HTML side and a JavaScript side. The IDs are the handshake between them.

    Random chooser

    Button → pick one safe suggestion → message.

    Checklist

    Checkbox → inspect checked state → message.

    Calculator

    Two inputs → add values → total or error.

    In input → processing → output, which part is the user’s choice or typed value?

    Use the recipe guide in the Codespace. Copy the matching HTML controls into your interface and the matching JavaScript into script.js.

  4. Test normal and edge casesLet evidence choose the next edit.

    Complete the guided baseline first

    Testing card

    1. Normal: provide the expected kind of input. What should happen? What did happen?
    2. Edge: leave it empty, choose the other option, or enter an unusual value. What should happen? What did happen?
    3. Make one repair to the code or label, then run both tests again.
    Remix

    Change the recipe data and result text.

    Builder

    Add validation or a second choice.

    Boss

    Write a small function, refactor repetition, or save a preference locally.

  5. Trace and explainMake the feature teachable.

    Commit with Meeting 7: working feature, sync, verify the commit, and stop the Codespace.

    Demo sentence: “The input is ____. The code processes it by ____. The visible output is ____. Our edge-case test caused us to ____.”

    Stuck ladder

    1. Compare the HTML IDs with the recipe comments.
    2. Run the normal and edge tests again.
    3. Read the console message and restore only the affected file.
    4. Ask a peer, teacher, or optional AI adviser for one diagnosis, not a rewrite.
