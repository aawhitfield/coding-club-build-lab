# AI Playbook

AI is optional. The project must remain completable with the starter, recipe cards, peers, and adviser.

## Ask → Check → Explain

Before asking:

1. What are we trying to change?
2. What have we already tried?
3. What specific help do we need?

After asking:

1. Change one thing at a time.
2. Run and test it.
3. Record the decision in `AI-LOG.md`.
4. Explain the retained code during the demo.

## Good prompts

- Explain this line as if I have never coded before.
- Which file probably controls this color?
- Why might clicking this button do nothing?
- Give me three button labels, not code.
- Suggest five test cases for this feature.
- Do not rewrite the whole project. Give us one next step.

## Do not

- Ask AI to generate the whole project.
- Keep code nobody on the team can explain.
- Enter student names, personal information, passwords, tokens, or API keys.
- Treat “the AI said it works” as testing.

## Log template

```text
Meeting:
What we were trying to change:
Prompt summary (no personal information):
What the tool suggested:
What we accepted, changed, or rejected:
How we tested it:
How we can explain the retained code:
```
