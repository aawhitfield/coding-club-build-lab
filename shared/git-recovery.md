# Git and Codespace Recovery

## Start of meeting

1. Open the team repository.
2. Open or resume the Codespace.
3. Use **Source Control → Sync Changes** before editing.
4. Open the meeting's `START-HERE.md` and the current project folder.

## End of meeting

1. Save every open file.
2. Open Source Control.
3. Write a short summary, such as `Meeting 2: added the third choice`.
4. Commit.
5. Sync or push changes.
6. Confirm the repository shows the new commit.
7. Stop the Codespace.

## If the project is damaged

- Use undo once or twice.
- Reopen the last saved version.
- Copy the meeting's `starter/` or `catch-up/` folder into a new working folder.
- Ask the teacher before deleting a repository.

Never share passwords, tokens, or account recovery codes.
