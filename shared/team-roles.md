# Team Roles

Rotate roles every meeting. A role is a way to contribute, not a ranking.

| Role | Job |
| --- | --- |
| Driver | Operates the Chromebook and makes the edits the team agrees on. |
| Navigator | Reads the directions, predicts behavior, and suggests the next change. |
| Designer/tester | Checks clarity, accessibility, appearance, and bugs. |
| Documentarian | Records contributions, AI use, bugs, and the demo explanation. |

With two students, combine Navigator + Documentarian and rotate Driver + Designer/tester. With three students, rotate the fourth role each meeting.

Only one person edits the shared repository at a time. Everyone should be able to explain the team’s current feature.
