# Showcase Demo Checklist

Use this before the gallery walk. Keep the demo to two minutes.

- [ ] The project opens from a fresh tab or shared preview.
- [ ] Someone can tell what the project is for in one sentence.
- [ ] We can name what the starter did before our changes.
- [ ] We can show one visible change and one working interaction.
- [ ] A teammate can explain the input → processing → output pattern.
- [ ] We tested the main path and one edge case.
- [ ] We can describe one failure, revision, or useful discovery.
- [ ] Every teammate has a speaking, testing, or documenting role.
- [ ] We do not claim that AI wrote work nobody on the team can explain.
- [ ] We have not included passwords, personal data, or private school-system information.

Suggested rhythm: 20 seconds for the problem, 60 seconds for the demo, 30 seconds for the code pattern, and 10 seconds for the team contribution.
